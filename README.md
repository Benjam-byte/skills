# AI Skills

Ce repo regroupe des fichiers `.md` servant de règles et d’instructions pour des IA.

## Structure

```txt
.
├── README.md
├── frontend/
│   ├── angular
│   ├── ionic-angular
│   ├── code
└── design/
    └── design.md
```

## Front-end

Le dossier frontend/ contient des règles pour aider une IA à générer du code front-end.

Certains fichiers sont généraux :

- coding-guidelines.md
- style.md
- performance.md
- security.md

Certains fichiers sont spécifiques à un framework ou une stack :

- architecture.md
- ionic.md

## Design

Le dossier design/ contient des règles destinées aux IA de design.

Ces fichiers servent à cadrer :

- la direction artistique ;
- la cohérence UI ;
- le mobile-first ;
- l’accessibilité ;
- les règles visuelles générales.

## Utilisation

Copier les fichiers utiles dans un projet ou les référencer dans les instructions d’un assistant IA.

Chaque fichier doit rester :

- court ;
- clair ;
- actionnable ;
- réutilisable.
